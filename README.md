## Escenario
Escenario B - Análisis de Ventas

## Descripción
Este proyecto realiza un análisis básico de ventas utilizando Python y herramientas de control de versiones.

## Estructura del proyecto

- datos/: contiene el archivo CSV de ventas
- scripts/: contiene el script principal
- resultados/: contiene el gráfico generado

## Herramientas utilizadas

- Python
- Git
- GitHub
- Jira
- Google Colab

## Ejecución

Ejecutar el siguiente comando:

python scripts/analisis_ventas.py
